# Learning JAVA

A comprehensive collection of Java learning projects and assignments covering fundamental concepts to advanced topics.

## Overview

This repository contains various Java assignments and projects developed while learning Java programming. The projects progress from basic concepts like arrays and flow control to more advanced topics including database connectivity and full-fledged applications.

## Project Structure

### Core Assignments

#### Basic Java Concepts
- **AssignmentArrayDemo.java** - Demonstrates array operations and manipulation techniques
- **AssignmentFlowControl.java** - Control flow structures including loops, conditionals, and decision-making

### Advanced Projects

#### 1. Student Management System (StudentManagementEx)
A comprehensive student management application with core features for managing student records and information.

#### 2. JDBC Student Management (JDBCStudentManagement)
Database-driven student management system using JDBC for:
- Database connectivity
- CRUD operations (Create, Read, Update, Delete)
- Data persistence
- Student record management

#### 3. Login System Application (LoginSystemApplication)
A secure login and authentication system featuring:
- User registration
- Login authentication
- Session management
- Password handling

#### 4. Restaurant Menu System (ResturantMenu)
A restaurant ordering system with:
- Menu management
- Order processing
- Item selection and pricing
- Order summary

#### 5. Swap Assignment
Data manipulation exercise demonstrating variable swapping techniques and data exchange operations.

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- IDE (Eclipse, IntelliJ IDEA, or VS Code with Java extension)
- Database (MySQL/PostgreSQL) for JDBC projects

### Installation

1. Clone the repository:
```bash
git clone https://github.com/unishajoshi/Learning-JAVA.git
cd Learning-JAVA
```

2. Compile Java files:
```bash
javac Assignments/*.java
```

3. Run a program:
```bash
java Assignments/AssignmentArrayDemo
```

### For JDBC Projects
1. Install and configure your database
2. Update database connection parameters in the project
3. Create required database tables
4. Run the JDBC programs
